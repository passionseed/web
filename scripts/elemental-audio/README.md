# Elemental element videos: sound clips

The real recordings the five element videos use (`scripts/render-elemental-<element>.mjs`). Each is a 14-second cut, re-encoded as MP3. All are CC0 (no permission or credit needed), found through Openverse. Every other sound in the videos (thuds, clatter, hum, fans, crackle, drones) is generated in code.
