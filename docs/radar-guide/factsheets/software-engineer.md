## The `start` chapter's first step

`first_step`: a one-page site about yourself, published to GitHub Pages. Free (S11), about 90 minutes for a first attempt, and it ends with a link the student made and can send to a friend. Certificates come last (start beat 5). Only `startCarousel@130` holds this field's start options. It is hidden on the page, and no `radar_skill_start_options` rows exist for this field (`radar_field_skills` has no rows for it, checked read-only on 2026-11-11). So the RadarSkillExperience rail is empty on `/radar/software-engineer`. See content fix 4.
