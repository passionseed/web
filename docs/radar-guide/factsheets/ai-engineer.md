## Safety and tone notes

- No hacking content in this career, so no legal-lab line is needed. The `start` first step uses photos of objects, not faces: on screen "ใช้รูปสิ่งของ ไม่ต้องใช้หน้าตัวเอง", because the viewers are minors.
- The `start` first step: free, about 60 minutes, ends with a trained model plus a table of where it fails on unseen photos (a first eval set, which is the core skill of the job). Certificates are named last ("เกียรติบัตรเอาไว้ท้ายสุด").
- The money chapter hook does not say จบใหม่ or เริ่ม, so it can show the full ladder; reel hook variant 2 ("จบใหม่สาย AI ได้เดือนละเท่าไหร่") leads with the entry figure, which is beat 1.
- Before recording `money`: the page card still says junior 35k-50k. Fix `salaryProgression@40` first (content-fixes item 3), or the clip and the card will disagree on the same screen.
- Before publishing `start`: the page has no published skills or start options for this field (anon read, 2026-11-11), and startCarousel `text@130` is hidden by design, so the `start` chapter would show only the skills text card. Add the start options in content-fixes item 6.
