- At most 3 messages per applicant: M4, one follow-up (M5) at 48 to 72 hours, and M10 on Friday. Stop after any "no".
- Under 20: **parent consent comes before payment.** The messages ask the parent to agree first, so nobody pays for a seat a parent then declines.
- **The parent consent link goes only to the parent**, in a LINE OA chat the parent opened by adding @passionseed. Never paste it into a student's DM: the parent page takes a typed name and a tick, so a student could agree for their parent. LINE OA can't start a chat from a LINE ID or phone number, so always ask the parent to add @passionseed.
- Each "Email parent link" or "Copy link for LINE" makes a new link and the old one stops working, even when the email fails to send. Re-send at most once, by one channel.
- Refunds: answer only from the refund steps on passionseed.org/shift/3. Don't quote company-brain `shift.md`, whose refund line disagrees with the site (a founder needs to settle that).

- `[a: ...]`, `[b: ...]`, `[c: ...]` wait on a founder decision below. If decided yes, delete the brackets and the letter label and send the Thai. If undecided or no, delete the whole line.
- `{curly braces}` are fill-ins: replace them, never delete the line.
