## Story: how to post it

1. Upload `elemental-ask-story.png`.
2. Add the **Questions** sticker over the empty sky under "ถามในกล่องนี้ได้เลย". Prompt: `สงสัยอะไรเรื่อง Elemental?`
3. Add a **Link** sticker near the bottom, above the date: `https://www.passionseed.org/hackathon/elemental?src=ig-qa`, label `สมัคร`.
4. Optional: reshare the feed post into a second Story frame so people see where to comment.

## The follow-up: from comments to an answer post

1. **When.** Post the ask after the extended-schedule post (HAC-75) is live, so answers can use the public dates. Collect for about 48 hours, then post the answers at least 3 days before sign-up closes (Fri 4 Dec 23:59), so the answers still move sign-ups.
2. **Collect.** The Meta connector only counts comments; by design it never reads their text (brain `meta-data.md`). So the person who runs the account copies the question text into the HAC-81 thread: feed comments, Story sticker replies and DMs. **Text only, no handles or names** (most askers are minors). Questions from the LINE group and the sign-up form go in the same list.
3. **Group.** An agent groups them by topic and counts each group. Topics come from the real questions, not from a list we guessed.
4. **Answer.** Answer the 5 to 8 biggest groups in one carousel in the Elemental look: the question in the asker's own words (no name), then a short answer. Every answer is checked against the brain (`numbers.md`, `decisions/log.md`, the hackathon page) and web `facts.ts` before it goes out. Anything not decided stays out, it doesn't get guessed.
5. **Close the loop.** Reply under each answered comment ("ตอบแล้วในโพสต์ล่าสุด") and DM the sticker askers; links in DMs and the answer Story use `?src=ig-qa`. Log each send on HAC-81.
6. **Measure.** Count comments (Meta connector, `instagram_posts`) and paid sign-ups with `src=ig-qa` (admin sign-up page). The pass line is Big's call.
